# Задачи 004: настоящие коммиты в Bitbucket

Работа идёт в ветке `feature/real-commits` от `main`. Коммиты, push и PR только по команде

Порядок важен: сначала весь код с тестами, потом сборка, потом прогон на живой базе против подделки Bitbucket. Короткая проверка миграции на базе внутри задачи 3 нужна, чтобы убедиться в поведении GORM до того, как на нём строится остальное
